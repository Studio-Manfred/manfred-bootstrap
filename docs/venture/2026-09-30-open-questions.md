# Open questions

> **Purpose:** the questions still waiting for an answer, a person, or a conversation. Distinct from the [honest gaps](./2026-09-30-q4-2026-plan.md#2-honest-gaps) (which are data we don't yet have and close through Q4 experiments). Open questions are decisions to be made, people to consult, and specific facts to look up. Each has an owner (who should answer), a "must be answered by" horizon, and where it feeds back into the venture docs.

## Rules of use

- **Every question has an owner.** If it's just "the team," it's not really assigned.
- **Every question has a deadline** — even soft ones. "TBD forever" is how open questions become forgotten questions.
- **Answering a question closes it here and gets folded into the relevant option doc.** This doc is a working list, not an archive.
- **A question that keeps recurring is a signal**, not a nuisance — it usually means the wrong person owns it, or the answer requires a conversation we've been avoiding.

## 9. What's NOT on this list

Deliberately excluded:

- Tactical implementation questions ("what CRM should we use?", "which email tool?") — these are decisions to make when we need to make them, not blockers now
- Details of pilot delivery ("what specific tool do we install first at pilot #1?") — those come from A1's discovery calls, not from planning
- Q3 2027+ questions — too far out; premature to enumerate

If a question feels operational rather than strategic, it belongs in a follow-up Linear ticket, not this doc.

## 10. How to close a question

When you answer one:

1. Write the answer in the relevant option doc (or Q4 plan) — the answer is now a decision that shapes the venture
2. Cross the question off in this doc (strikethrough, don't delete — the audit trail matters)
3. Ledger the ruling in the STU-985 comments so future collaborators see the reasoning
4. If the answer created new questions, add them here with owner + deadline
